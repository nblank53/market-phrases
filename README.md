# Market Phrases

A small offline phrase trainer for the December Christmas market trip: France, Switzerland and Italy.
Plain HTML/CSS/JS, no build step and no dependencies. All phrases come from `phrases.json` at runtime.

## Run it locally

Requires Node 18+.

```bash
cd C:\Dev\market-phrases
npm start            # same as: node server.js
```

Open http://localhost:8768. The server also prints a `http://192.168.x.x:8768` address you can open
on your phone while it's on the same Wi-Fi.

> Opening `index.html` straight from disk won't work: browsers block loading `phrases.json` from `file://`.

### On your phone, offline

Browsers only allow offline mode and "Add to Home Screen" install on **https** or `localhost`.
The Wi-Fi address above works for practising, but it won't stay available offline. For the trip, put the folder on any
free static host (GitHub Pages, Netlify Drop, Cloudflare Pages). No build step is needed, just upload the folder.
Then open the site on your phone once and install it:

- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** ⋮ → Install app

After the first visit everything, including the phrases, is cached and works in airplane mode.

**Audio** uses your device's built-in voices (Web Speech API). If a phrase plays in an English accent,
install the French / German / Italian voice in your phone's or computer's speech settings.

## Features

- **Practice:** pick a country (or All), filter by category and priority, then Learn or Quiz.
- **Learn:** flashcards with native text, phonetic and audio. Tap to reveal the English and any note.
  On a laptop: ← → to move, Space to flip, S for audio.
- **Quiz:** four modes: Meaning (native → English), Say it (English → native), Type it (typed, accents and
  punctuation optional, small typos forgiven on long phrases), and Listen (audio → English). Keys 1–4 pick, Enter continues.
- **Spaced repetition:** Leitner boxes 1–5. A miss sends the phrase to box 1 and brings it back later in the
  same session. Correct answers move it up one box. A phrase comes back after 0, 1, 3, 7 or 14 days depending on its box.
  Sessions start with due phrases, then new must-know ones.
- **Progress:** mastery per country and category, a daily streak, your weakest phrases, and a "Drill these" button.
- **Trip:** for each country, emergency numbers (tap to call), local tips and the must-know phrases in large
  type. Tap a phrase to show it full screen to someone. Switzerland has a "Where are you?" switch:
  German (Zurich/Basel/Lucerne/Bern), French (Geneva/Lausanne/Montreux) or Italian (Ticino).
- Light/dark theme follows your device. The ◐ button cycles auto → light → dark.

Progress is saved in your browser's `localStorage`, keyed by phrase `id`. It stays on that device.
Laptop and phone track progress separately.

## Adding phrases

Add an object to the `phrases` array in `phrases.json`:

```json
{"id": "fr-077", "country": "fr", "language": "French", "category": "christmas_market", "priority": 2,
 "native": "Un pain d'épices", "english": "Gingerbread", "phonetic": "uhn pan day-PEESS",
 "note": "Optional tip shown on the card."}
```

- `id` must be **unique and never reused or renamed**. Progress is stored by id, so new phrases show up as
  "new" and existing progress is kept.
- `country` must match a `meta.countries[].code`. `category` must be one of `meta.categories`.
- `priority`: 1 = must-know (shown in Trip mode), 2 = useful, 3 = nice to have.
- Optional parts in `native` are understood by the typed quiz: `Enchanté(e)` accepts both forms, and
  `perso/a` accepts `perso` or `persa`.
- To add a whole country, add it to `meta.countries` with a `language_code` (e.g. `de-AT`) for audio.

Run `npm test` afterwards. One of the tests checks `phrases.json` for duplicate ids and unknown countries or categories.
If the app is installed on a phone, it picks up new phrases the next time it's opened online.
App code updates download in the background and show up on the following launch.
Bump `VERSION` in `sw.js` if you remove or rename files.

## Tests

```bash
npm test
```

Uses Node's built-in test runner. The tests cover answer normalization (accents, ß, umlauts as ae/oe/ue,
optional endings, typo tolerance), Leitner scheduling, session picking, multiple-choice distractors,
the streak and mastery stats, and validation of `phrases.json`.

## Files

```
index.html             app shell
styles.css             mobile-first styles, light + dark
app.js                 UI: views, quiz flow, speech, storage
logic.js               pure logic (normalization, Leitner, distractors, stats); unit tested
phrases.json           the data
sw.js                  service worker (offline cache)
manifest.webmanifest   PWA manifest
icons/                 app icons (PNG generated by `npm run icons`)
server.js              tiny zero-dependency static server
tests/logic.test.js    unit tests
```
